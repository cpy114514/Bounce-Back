# D-ElasticPool

弹力水池的静态外观。没有碰撞体，没有脚本，也没有水面。碰撞仍由关卡里的 `Elastic Pool Surface` 负责，水面留给任务 G。

## 摆放

| | |
| --- | --- |
| 锚点 / 轴心 | 水面中心，世界坐标 `(-1.40, 0.45, 2.05)` |
| Prefab | `Prefabs/D-ElasticPool.prefab` |
| 根节点 | 位置放在锚点，旋转 `(0,0,0)`，缩放 `(1,1,1)` |
| 轴向修正 | 子节点 `AxisCorrection`。导入后约为 X 轴 270°、缩放 100。这是 Blender 米制网格进 Unity 的轴向，不要清掉，也不要烘焙进顶点 |

根节点在原点时，网格已经相对水面中心建模。放到锚点且旋转为 0 后，与布局 JSON 重合。

## 尺寸

世界范围：`(-3.765, -0.22, -0.515)` 到 `(0.965, 0.55, 4.615)`，约 4.73 × 0.77 × 5.13 米。

| 部分 | 位置 |
| --- | --- |
| 池沿 | 宽 0.25 m，内侧面贴着碰撞体四个立面，顶面 y = 0.49 |
| 北沿（两墩之间） | 最高 y = 0.505，低于 0.55，不挡球从水面弹向升降墙 |
| 角墩与尖顶 | 杏橙色，只在四个外角。尖顶顶点 y = 0.55 |
| 上级台阶 | 顶面 y = 0.18，向外 0.50 m |
| 下级基座 | `MV_Rose`，顶面 y = -0.02，底面 y = -0.22，向外 0.74 m |
| 池底浮雕 | 灰缝顶面 y = 0.03，与碰撞体底面重合；马赛克最高 y = 0.0495，高出碰撞底 0.0195 m |

东侧角墩外缘 x = 0.565。露台碰撞从 x = 0.60 开始，间隙 0.035 m。台阶和基座的顶面都低于露台底面 y = 0.30。

升降墙完全降下时，其体积会穿过北侧池沿；抬起后的姿态与本模块不相交。整合时不要为了这个初始姿态去切池沿。

## 网格与材质

852 个三角面（Blender 源网格 572 顶点；Unity 按平面法线拆成 1720 顶点）。4 个材质槽。FBX 导入不会保留 Blender 里的槽顺序，Prefab 按几何对上了名字：

| 材质 | 用在 |
| --- | --- |
| `MV_Ivory` | 池壁、池沿、上级台阶、池底灰缝、中央菱形 |
| `MV_Apricot` | 池沿外缘饰线、四角方墩、尖顶 |
| `MV_DomeBlue` | 池底同心方格浮雕 |
| `MV_Rose` | 落到 y = -0.22 的下级基座 |

## 给任务 G 的水面

本模块不含水面。水面是一块水平矩形，边与池壁内侧面重合，不要抬过 y = 0.45。

- 世界中心：`(-1.40, 0.45, 2.05)`
- 世界范围：x `-3.025` 到 `0.225`，z `0.225` 到 `3.875`，y = `0.45`
- 相对 Prefab 原点：中心 `(0, 0, 0)`，x `-1.625` 到 `1.625`，z `-1.825` 到 `1.825`

## 对齐

相对 `Elastic Pool Surface` 四个内立面的误差为 0（容差 0.02 m）。池沿顶、北沿高度和池底浮雕都在上面的数值内。验收记录在 `Documentation/D-ElasticPool_UnityValidation.txt`。

## 重跑

```text
blender.exe --background --python-exit-code 1 --python "ArtSource/Prototypes/D-ElasticPool/build_d_elastic_pool.py"
```

然后在 Unity 菜单执行 `Tools/Bounce Back/Build D-ElasticPool Preview`。已打开的场景有未保存改动时，这个菜单会直接停下来。
