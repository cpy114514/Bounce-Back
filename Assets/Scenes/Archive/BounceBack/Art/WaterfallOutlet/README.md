# 瀑布口出水饰件 · Waterfall Outlet

纯视觉资产：一件白石挑檐和一条独立的淡蓝水舌。没有踏板、落球面、溅水装饰、Collider、Rigidbody、动画或玩法组件。

## 文件

- 可编辑源文件：`ArtSource/Kimi/WaterfallOutlet/WaterfallOutlet.blend`
- 可重建脚本：`ArtSource/Kimi/WaterfallOutlet/build_waterfall_outlet.py`
- 独立挑檐：`FBX/WaterfallOutlet_Stone_Eave.fbx`
- 独立水舌：`FBX/WaterfallOutlet_Water_Tongue.fbx`
- 便捷组合：`FBX/WaterfallOutlet_Assembly.fbx`，内部仍是上述两个独立网格，枢轴相同
- 精确尺寸与网格统计：`Documentation/WaterfallOutlet_Dimensions.json`
- Unity 实测导入记录：`Documentation/WaterfallOutlet_Unity_Validation.txt`
- 等距全景与檐口近景：`Preview/`

无外部贴图依赖。颜色由材质槽表达；水体的三条浅色水纹已经合并进水舌网格，不是额外场景物体。

## 共享原点与轴向

单位为米。Unity 中 **X 横向、+Y 向上、+Z 朝外出水**。

两件模型的共享局部原点均为 `(0,0,0)`：水舌顶部附着边的中心，同时也是石材前上檐口的中心。石材位于原点的 `-Z` 一侧和 `Y≤0`；水体先从 `-Z` 的短水面经过原点，再向 `+Z` 翻出并沿 `-Y` 下落。

在 Unity 对齐时：

1. 把两件模型放在同一个父节点下，二者的本地位置都设为 `(0,0,0)`。
2. 保留 FBX 导入节点自身的单位/轴向转换；外层父节点使用旋转 `(0,0,0)`、缩放 `(1,1,1)`。独立 FBX 根节点显示的 `-90° X` 旋转和 `100` 缩放属于文件单位/轴向换算，Unity 实测世界尺寸仍正确，不要手动归一。若想减少这层处理，直接使用组合 FBX 的根节点即可。
3. 移动或旋转外层父节点来对准你的安装面。需要改变落差时，只调水舌的 Y 缩放；需要改变整体标称宽度时，同时调两件的 X 缩放。
4. 踏板和落球面由你在 Unity 单独对齐，本资产没有替它们预留碰撞或物理位置。

## 尺寸与造型

| 项目 | 尺寸 / 说明 |
| --- | --- |
| 挑檐标称宽 | **1.60 m**，X 范围 `[-0.80,0.80]` |
| 挑檐主体 | 高 `0.30 m`，深 `0.76 m`；前上缘为 `Y=0,Z=0` |
| 水舌顶部附着边宽 | **1.44 m**，中心精确位于共享原点 |
| 水舌默认落差 | **2.20 m**，底边 `Y=-2.20` |
| 水体基础厚度 | `0.026 m`；基础水体封闭，浅色水纹为贴合表面的浅层几何 |
| 水面过渡 | 檐顶向后延伸 `0.54 m`，让等距镜头能读出“经过檐口再下落” |
| 折面 | 四条宽折带，平板法线；三条断续浅色水纹 |
| 材质 | 两种白石色；三种淡蓝水色和一种浅泡沫色，均为不透明、无贴图 |

精确包围盒以 JSON 记录为准，水体包围盒还包含厚度、折面和水纹的微小偏移。

## Blender 源文件

`01_DELIVERY` 只包含两件交付网格及各自位于原点的根节点；`90_PREVIEW_CAMERA_LIGHT` 仅用于渲染，不会导出。两个网格不共享 Mesh 数据，可分别编辑、替换材质或缩放。
